# 한진개발 — Astra 1

https://majitap.github.io/hanjin-astra1/

우미 레퍼런스의 대형 사진·중앙 타이포·사업영역 전환을 참고한 블루 기반 기업 사이트.

정적 HTML/CSS/JavaScript. 별도 설치·빌드 불필요. main 브랜치 루트를 GitHub Pages로 배포합니다.

- PC 본문 20px, 모바일 본문 17px. 메뉴 19px, 모바일 메뉴 32px 이상. 나눔스퀘어 네오.
- 3장 이미지 크로스페이드, 이미지 확대/이동, 일시정지 및 다음 이미지 버튼. 모션 감소 설정 지원.
- 키보드 접근 가능한 4개 분야 탭.
- 고정 헤더, 전체 메뉴, 스크롤 등장, 카운터, 모바일 상담 버튼.
- 기존 문의 폼 ID, 오류 시 입력 보존, 중복 제출 방지, 복사 대체 기능 유지.

공개 Web3Forms 폼 ID는 메일 비밀번호가 아닙니다. 실제 수신 주소는 기존 Web3Forms 관리 화면에서 관리합니다.
